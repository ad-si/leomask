# Leo Mask

Landing page for [Leo Mask](https://www.leomask.com),
a songwriter and producer from Germany.

The site is a static HTML page linking to music streaming providers
and social media profiles.


## Deployment

Pushes to `master` are deployed to GitHub Pages
via `.github/workflows/pages.yml`,
which stages `index.html`, `img/`, and `styles/`
and publishes them to <https://www.leomask.com>.
